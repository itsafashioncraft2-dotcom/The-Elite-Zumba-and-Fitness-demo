THE ELITE ZUMBA & FITNESS STUDIO - WEBSITE DEMO
================================================

HOW TO OPEN
Double-click index.html. Keep the "assets" folder next to it.

WHAT TO EDIT (all inside index.html)
Search for "EDIT HERE ONLY" near the bottom of the file:
  WHATSAPP_NUMBER  - country code + number, digits only
  PHONE_NUMBER     - number for the "Call now" buttons
  MAPS_LINK        - Google Maps directions link
  MESSAGES         - the pre-filled WhatsApp messages
  PROGRAMS         - list of programs shown in the Programs section

PHOTOS
Replace the files in assets/images/ with better photos, keeping the same
file names. Use large, sharp originals: hero-gym-floor.jpg at least 1600 px wide.

STILL PLACEHOLDERS
  - Facebook link in the footer
  - Zumba section has no photo yet
  - Contact section shows a Google Maps card, not a live embedded map
  - Footer says "Website Demo Concept" - remove for the live site

TO PUT IT ONLINE
Upload the whole folder (index.html + assets) to any static host,
for example Netlify, Vercel or GitHub Pages.
